# Release verification — 1.0.0

2026-10-02, macOS arm64, Node 24.12.0, pnpm 12.8.1. The research gate preceded implementation. This is a locally prepared release candidate, not a published or Chrome Web Store-approved item.

## Executed checks

- Frozen dependency installation and exact lockfile; zero production npm dependencies.
- Visual identity verification: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` and `pnpm package` PASS; 40 unit/integration/performance tests PASS, production artifact inspection PASS.
- `pnpm test:e2e`: PASS (3/3, 58.3 seconds). Real MV3 extension in disposable Chrome for Testing 153.0.8010.12. Three scenarios cover automatic/manual backup, groups/pins/windows, export/import, invalid files, retention, 100+ tabs, worker disposal and durable alarm recovery, browser restart, local version update, interrupted restore and renderer-crash recovery.
- `pnpm format:check`: PASS.
- `pnpm audit --json`: 0 known advisories at all reported severities (including dev tools); raw report in docs/security/dependency-audit.json.
- Independent rebuild and ZIP packaging produced identical SHA-256.
- ZIP integrity checked; 15 entries, manifest.json at root, version 1.0.0. No test files, source maps, remote scripts or dev endpoints.
- Source review found no network client, HTML injection sink, eval, Function constructor, sync storage or site-content collector in src/. Allowed URL scheme strings are data validation only.
- Palette migration: 82 token contrast pairs passed across light/dark; text minimum 4.59:1, tested non-text minimum 3.03:1. [Identity decisions and contrast details](../architecture/visual-identity.md).
- Repository-wide source/build scan found no old green theme literals. Authored color literals are centralized in src/shared/theme.css; generated SVG/PNG/build assets consume them.
- Store images regenerated and inspected: 128×128 RGBA PNG icon, 440×280 RGB promo, three 1280×800 RGB screenshots. Library, dark and settings layouts visually inspected.

A transient macOS headless compositor screenshot error occurred after the large-tab test. The test now closes the disposable test tabs after restore assertions, brings the UI forward, and retries only screenshot capture for up to five seconds. Product assertions are not retried as whole test cases.
