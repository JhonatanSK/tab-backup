# Permissions review

Reviewed against the [official warning list](https://developer.chrome.com/docs/extensions/reference/permissions-list) on 2026-10-02. Installation warning wording can vary by locale/platform and combinations.

| Permission                 | Feature and accessed data                                                                                                                     | Alternative considered                                                                                                         | Chrome warning                       | Removal consequence                                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| tabs                       | Read open-tab URL/pending URL and title, pinned/order/window membership; create/inspect restored tabs. Favicon field is available but unused. | activeTab sees only a user-selected tab; broad host grants are more invasive.                                                  | “Read your browsing history”         | URLs/titles unavailable across all open tabs; useful automatic recovery impossible. This does not authorize the history API. |
| tabGroups                  | Group title, color, collapsed state and events; recreate group structure.                                                                     | Omit groups and lose promised structure.                                                                                       | “View and manage your tab groups”    | Group metadata and updates fail; grouped restore incomplete.                                                                 |
| storage                    | Persist scheduler, settings, error codes, restore progress across worker termination and browser restart.                                     | IndexedDB also possible, but Chrome storage is a small, explicit settings/control store; snapshots use IndexedDB transactions. | None listed                          | Worker control-state persistence fails.                                                                                      |
| alarms                     | Durable backup fallback and 15-minute deduplicated safety check.                                                                              | Timers alone are lost at worker suspension.                                                                                    | None listed                          | Pending captures can be lost when worker stops.                                                                              |
| downloads — omitted        | Export uses user-triggered Blob + download link, in extension UI.                                                                             | Chosen alternative needs no permission.                                                                                        | Would warn about managing downloads. | No feature loss; already omitted.                                                                                            |
| unlimitedStorage — omitted | Neither necessary for 20 ordinary snapshots nor a substitute for retention.                                                                   | 32 MiB app limit, quota error handling, optional browser persistence and export.                                               | None listed                          | Ordinary browser quotas/eviction still apply; UI explains internal storage limits.                                           |

No host_permissions, optional permissions, content scripts, web-accessible resources or externally_connectable. No history, cookies, scripting, activeTab, webRequest or all-URLs grant. windows and runtime do not require extra permissions for the calls used. The manifest prevents incognito access; the builder also filters private windows/tabs.
