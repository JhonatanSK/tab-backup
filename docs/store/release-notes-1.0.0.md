# TabBackup 1.0.0

Initial local-first release. Automatic and manual snapshots, latest-20 retention, transactional local storage, safe file import with preview, JSON export, and restore into new windows with pinned tabs and groups. English and Brazilian Portuguese UI, system light/dark themes, keyboard controls and privacy explanations.

Known boundaries: internal/extension/file URLs are skipped during restore; no incognito, page content, scroll/forms/authentication recovery or cloud backup. No guarantee for changes made just before a crash. Interrupted restores are reported and require inspection before retry. Internal storage is removed on uninstall. Larger configurable history and paid capabilities are planned, not offered in this release.
