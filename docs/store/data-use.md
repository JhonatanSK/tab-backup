# Privacy practices / dashboard data use

Disclose local handling of browsing activity: URLs and titles of currently open normal-window tabs, plus group labels and session structure. This is necessary for the prominently described backup and restore feature. Do not select blanket claims that no user data is handled: the current official FAQ requires disclosure even for local-only processing.

There is no transmission to the developer or third parties, no analytics, sale, advertising, creditworthiness profiling, payment data collection, location collection, personal communications scraping, cookies or site-content capture. Arbitrary URLs/titles may incidentally contain sensitive personal information; this is disclosed in the policy. No access to password stores or authentication cookies. Recognizable credentials in URLs are removed, but do not claim arbitrary URLs cannot contain secrets.

Purpose: functionality only. Location: extension's IndexedDB and local Chrome storage. Retention: newest 20 distinct snapshots, user deletion, uninstall; exported files under user control. Transfer: only user-initiated download/import; opening restored URLs triggers normal site navigation, not backup upload.

Certifications to check only after reviewing the actual dashboard wording: no sale/transfers outside approved use, no unrelated use of data, no use for lending/credit decisions. Publish policy URL, match all answers to shipped code, and review again if any network/license/payment feature is later added.
